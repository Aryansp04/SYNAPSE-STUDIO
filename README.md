# SYNAPSE STUDIO — Next-Gen 3D Interactive Website

An award-winning, state-of-the-art interactive digital studio website built with Three.js WebGL, dark luxury glassmorphism, spring physics micro-interactions, real-time shader sandbox, and interactive pipeline simulators.

---

## 🌟 Key Features

1. **3D WebGL Interactive Hero**:
   - Multi-layer Three.js particle constellation, rotating cybernetic icosahedron, crystalline dodecahedron, and dual additive energy orbit rings.
   - Real-time mouse physics with inertia deceleration and drag rotation.
   - Floating holographic glass telemetry chips (`GPU Compute: 120 FPS` & `Inertia Drag: Real-time Physics`).

2. **Interactive Disciplines & Pipeline Studio**:
   - **3D WebGL Pipeline**: Live render pass switching (`Wireframe`, `PBR Shaded`, `Normal Map`, `Point Cloud`) and 4-stage architecture stepper.
   - **Generative AI UX**: Live streaming token terminal with real-time telemetry (`TTFT`, throughput, confidence).
   - **FinTech High-Frequency Bench**: Streaming L2 Orderbook ladder with flashing bids/asks and 50k order stress-test trigger.
   - **Design System Studio**: Live spring physics playground with slider controls and click-to-copy color token swatches.

3. **Real-Time Generative Sandbox**:
   - Live deformable wavefield responding to cursor proximity with real-time sliders for density, velocity, and distortion.

4. **Filterable Case Studies & Case Study Modals**:
   - Filter by *Spatial & WebGL*, *FinTech & Quant*, and *AI & Creative* with detailed architectural breakdowns.

5. **Tactile Web Audio API Synthesizer**:
   - Pure Web Audio oscillator synthesis with hover clicks, crisp button presses, and ambient sound toggle.

---

## 🚀 Quick Start

Run locally with any static web server (such as Python):

```bash
# Python 3
python -m http.server 5173

# Or npx serve
npx serve .
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
